LoginApp - tela de login + painel (C# / .NET 8 / WPF)

Requisito: .NET 8 SDK (Windows).

Testar:
  dotnet run

Gerar o .exe:
  dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
  (sai em bin\Release\net8.0-windows\win-x64\publish\)

Onde mexer:
  AuthService.cs     -> regra de validacao do token (hoje: minimo 6 caracteres)
  MainWindow.xaml    -> tela de login
  AppWindow.xaml     -> painel (menu lateral, dashboard, projetos, configuracoes, sobre)
  logo.png / wallpaper.jpg -> troque as imagens mantendo o mesmo nome
